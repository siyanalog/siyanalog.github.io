# Portfolio skeleton

Static GitHub Pages-ready starter site.

## Pages

- `index.html` — Home + About Me section
- `projects.html` — Project category selector
- `hardware.html` — Hardware projects
- `software.html` — Software / firmware projects
- `experience.html` — Experience
- `blog.html` — Blog index
- `styles.css` — intentionally simple shared styling

## Publish

Copy these files into the root of your GitHub Pages repository and commit/push them. GitHub Pages will use `index.html` as the homepage.

This version intentionally keeps content and visual design minimal so the information architecture can be settled first.
